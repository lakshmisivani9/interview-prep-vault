# 📚 Interview Prep Vault

Interview Prep Vault is a full-stack application where users can store and practice interview preparation questions.

## Features

- User Registration and Login
- JWT Authentication
- Add Questions
- View Questions
- Database Storage

## Technologies Used

- React.js
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- H2 Database

## Concepts Covered

- React Components
- React Router
- API Calls
- Form Handling
- REST APIs
- CRUD Operations
- JPA and Database Integration
- JWT Authentication
- Spring Security


## Learning Outcome

Learned how frontend and backend communicate, how APIs are created, how authentication works, and how data is stored in a database.
